# Data Directory

Use this directory only for small, shareable, processed examples.

Do not commit full CFD outputs, TELEMAC outputs, VTK frame sequences, large Excel files, PDFs, or raw result archives directly to GitHub. Keep those in the local workspace or publish them through a research data archive.

Suggested small files for GitHub:

- Cleaned CSV examples used by `scripts/generate_visuals.py`
- Figure-ready summary tables
- Metadata files describing full datasets
